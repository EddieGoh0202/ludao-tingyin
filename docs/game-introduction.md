# 鹭岛听音 · 用一台收音机，听见厦门

> 一款像素风闽南话启蒙游戏。带上阿公留下的旧收音机，在厦门的老厝、市场、骑楼、海岛、渔村和古寺之间调频收音，把散落在街巷里的闽南话一句一句收进你的声音簿。


## 一、为什么做这个游戏

我是厦门人。我最早开口说的是闽南话，到了幼儿园小班才学会说普通话。

对我来说，闽南话是一种很深的感情。阿嬷在灶脚喊我食饭，阿公在藤椅上讲古，厝边阿姨在门口问"食饱未"，这些声音是我对家最早的记忆。闽南话把我和家乡的土地连在一起，也把我和远方的人连在一起。在台湾、在南洋、在世界各地，只要听到一句"汝好"，就知道遇到的是同一片乡音里长大的人。

这些年，闽南语歌曲也在变化。过去提起闽南语歌，大家先想到的是《爱拼才会赢》里的拼搏，《雨水我问你》里的情爱。现在，闽南语歌已经走进了更大的天地，有摇滚，有抒情，也有很私人的自白。这门语言没有老去，它还在长出新的样子。

可是对很多年轻人和外地朋友来说，闽南话还是"听得到、听不懂、开不了口"。所以我做了《鹭岛听音》，想给对闽南话感兴趣的朋友一个轻松的入口：不用背课本，先去听，听街坊怎么讲话，听老板怎么讲价，听阿嬷怎么叮咛。听多了，自然就想开口。希望这个游戏能帮大家迈出闽南话的第一步，也感受一点闽南风韵。

## 二、游戏玩法

### 1. 调频收音：核心玩法

玩家手里有一台旧收音机，频段是 87–108 MHz。厦门的每一句闽南话都藏在某个频率上。

- **走近声源**：离说话的地方越近，信号越强。
- **转准频率**：频率对得越准，声音越清晰，杂音越小。
- **锁定声音**：对准频率并保持 1.5 秒，就能把这句声音"收"下来。

收音过程中，杂音大小、人声音量和音色闷不闷都会随信号强度实时变化，就像真的在拧一台老收音机找台。


### 2. 听懂它：七种挑战

每锁定一句声音，都会弹出一道小挑战，确认你真的听懂了。全游戏共 120 道挑战，分七种题型：

| 题型 | 玩法 |
|---|---|
| 听音选义 | 听一句话，选出它的意思 |
| 对话应答 | 别人这样说，你该怎么回 |
| 找物 | 听到名称，在画面里找到对应的东西 |
| 排序 | 把打乱的词排成一句通顺的闽南话 |
| 声调辨别 | 分辨听起来很像、声调不同的词 |
| 俗语填空 | 补全一句闽南俗语 |
| 跟读 | 听完自己开口说一遍 |

挑战没有失败惩罚。答错可以再试一次，两次都没答对也能以一星收下，之后在复习里再练。

### 3. 走遍鹭岛：六个场景

收集的声音越多，能去的地方越多。

| 场景 | 解锁条件 | 你会听到 |
|---|---|---|
| 外妈老厝 | 开局即可进入 | 阿嬷、阿公和厝边的家常话，功夫茶、出砖入石、天井古井 |
| 八市 | 收集 6 句 | 鱼贩吆喝、讨价还价，土笋冻、海蛎煎、杆秤 |
| 中山路 | 收集 14 句 | 骑楼下的沙茶面、花生汤、馅饼，中秋博饼 |
| 鼓浪屿 | 收集 24 句 | 钢琴声、万国建筑、三角梅、日光岩 |
| 曾厝垵 | 收集 34 句 | 讨海人的话、烧肉粽、石敢当、送王船 |
| 南普陀 | 收集 46 句 | 晨钟、素饼、敬香、"佛"字石刻 |


### 4. 早起、中昼、下昏、暗暝

游戏里有四个时段，画面色调跟着变。不同时段能听到的声音也不一样：早上的市场最热闹，夜里的渔村有另一番话要讲。

## 三、游戏亮点

**用"听"来学，不用"背"。** 玩家先在场景里找到声音，再去理解意思，学习顺序和小孩学母语一样：先听熟，再开口。

**每句话都有台罗拼音。** 对话和挑战里可以显示台罗拼音，想跟读的朋友能看着拼音模仿发音，也方便以后自己查词典。

**有生活气息的厦门。** 六个场景都按真实地方的样子来画：燕尾脊、出砖入石的红砖墙、中山路骑楼、鼓浪屿的三角梅、曾厝垵的王船、南普陀的"佛"字石刻。所有美术都是用代码一笔一笔画出来的像素画。


**像在听街坊讲话。** NPC 有半身立绘和特写背景，对话像在看一部小小的视觉小说。阿嬷一句"汝转来矣！紧入来坐，日头遮大"，就是很多厦门人回外妈家时听到的第一句话。


**两个厦门味小游戏。**
- **八市砍价**：用闽南话和摊主讲价，讲得好就能便宜买到海鲜。
- **中山路博饼**：厦门中秋最有名的习俗。掷骰子，看能不能博到"状元"。


**24 张闽南文化科普卡。** 分饮食、建筑、风俗、工艺、自然五类。走到场景里的小物件旁就能打开，讲清楚一样东西的来历，并附上相关的闽南话词语。

**学过的会帮你记住。** 游戏用间隔复习（SRS）安排复习时间，快忘的词会再次出现。另有 13 个任务（如"阿嬷的茶""会晓讲价""琴岛初听""鹭岛听音人"）、28 条词汇表和一本声音簿，记录你在厦门收到的每一句话。

**有闽南语歌陪着走。** 标题页和地图播放魏如萱《彼个所在》，老厝播放萧煌奇《阿嬷的话》，鼓浪屿播放周杰伦《流浪诗人》。这三首歌也正好代表了闽南语歌这些年走向抒情、自白和更多元风格的变化。

## 五、操作方式

- 移动：方向键 / WASD，或用鼠标点击地面
- 调频：Q / E，按住 Shift 微调
- 交谈、打开科普卡：空格 / 回车，或点击人物
- 打开地图：M
