# 鹭岛听音 · 用一台收音机，听见厦门

一款像素风闽南话启蒙网页游戏。带上阿公留下的旧收音机，穿过厦门的老厝、市场、骑楼、海岛、渔村和古寺，调频收音，把街巷里的闽南话一句一句收进声音簿。

## 为什么做这个游戏

我是厦门人。我最早开口说的是闽南话，到了幼儿园小班才学会说普通话。

阿嬷在灶脚喊我食饭，阿公在藤椅上讲古，厝边阿姨在门口问“食饱未”，这些声音是我对家最早的记忆。闽南话把我和家乡的土地连在一起，也把我和远方的人连在一起。在台湾、在南洋、在世界各地，只要听到一句“汝好”，就知道遇到的是同一片乡音里长大的人。

这门语言没有老去，它还在长出新的样子。但对很多年轻人和外地朋友来说，闽南话还是“听得到、听不懂、开不了口”。我想用这个游戏给大家一个轻松的入口：不用背课本，先去听街坊怎么讲话、老板怎么讲价、阿嬷怎么叮咛。听多了，自然就想开口。

## 怎么玩

收音机频段为 **87–108 MHz**。靠近声源，再调整频率，信号越强、频率越准，声音就越清晰。保持锁定约 **1.5 秒**，进入理解挑战，完成后收集这句乡音。

游戏提供听音选义、对话应答、找物、排序、声调辨别、俗语填空、跟读七种挑战，共 120 道。挑战可以重试，也可以之后通过复习继续练习。

| 场景 | 解锁条件 | 听见厦门 |
| --- | --- | --- |
| 外妈老厝 | 开局可进入 | 家常话、功夫茶、红砖老厝 |
| 八市 | 收集 6 句 | 鱼贩吆喝、讨价还价、闽南小吃 |
| 中山路 | 收集 14 句 | 骑楼、沙茶面、中秋博饼 |
| 鼓浪屿 | 收集 24 句 | 钢琴、万国建筑、三角梅 |
| 曾厝垵 | 收集 34 句 | 讨海人、烧肉粽、送王船 |
| 南普陀 | 收集 46 句 | 晨钟、素饼、敬香与古寺 |

四个时段“早起、中昼、下昏、暗暝”带来不同色调和声音。旅途中还可以与 NPC 交谈、查看台罗拼音、阅读闽南文化科普卡，在八市砍价、在中山路博饼。声音簿和间隔复习系统帮助记录与巩固收集到的词句。

## 操作

| 操作 | 按键或方式 |
| --- | --- |
| 移动 | 方向键 / WASD，或点击地面 |
| 调频 | Q / E；按住 Shift 微调 |
| 交谈、打开科普卡 | 空格 / 回车，或点击人物 |
| 打开地图 | M |

建议使用带键盘的电脑浏览器体验，并开启声音。存档保存在当前浏览器的本地存储中，清除站点数据会影响存档。

## 本地运行

需要 Node.js 和 npm。在本项目目录执行：

```sh
npm ci
npm run dev
```

打开 `http://127.0.0.1:9000`。

```sh
npm run build     # 内容校验、TypeScript 检查与生产构建
npm run preview   # 在 http://127.0.0.1:9001 预览生产构建
```

生产文件输出至 `dist/`。仓库包含 GitHub Actions Pages 发布工作流；完成仓库的 GitHub Pages 配置后，实际游玩地址以 GitHub 部署结果为准。

## 技术与内容

- Phaser 3：场景、角色与像素画渲染。
- TypeScript + Vite：开发、类型检查与静态构建。
- Web Audio：收音机信号、噪声和语音播放。
- JSON 内容配置：场景、声音、挑战、任务和文化知识。
- 浏览器 localStorage：本地存档。

介绍材料统计了 **282 段语音埋点**，覆盖声音词条、NPC 对话、科普卡和小游戏；这是语音入口数量，不表示 282 段录音均已完成或可播放。实际可播放内容以当前构建与素材为准。
